# quAnswer-mpdcHDWIwqen

フロント業務アンケートの集計結果ページ。
アンケートフォームと同じく、ページはパスワードで暗号化してあり、パスワードを知っている人だけが開ける。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 暗号化した集計ページ（パスワード入力画面つき） |
| `tools/encrypt.mjs` | HTMLをパスワードで暗号化するツール（入力ミスの制限つき） |
| `tools/salt.txt` | 暗号化に使う塩（アンケートフォームと共通。消さないこと） |
| `tools/parse.py` | 回答txtを読み込む |
| `tools/agg.py` | 設問ごとに集計する |
| `tools/template.html` | 集計ページのひな形（集計結果は入っていない） |
| `tools/build.py` | 集計して `plain/summary.html`（平文）を作る |

次のものは**リポジトリに置かない**（`.gitignore` で除外）。リポジトリは公開されているため。

- `raw/` … 回答の原文（txt）
- `plain/comments.json` … 自由記述を言い換えた要約と、ページ内のまとめの一文
- `plain/summary.html` … 暗号化前の集計ページ

## しくみ

- パスワードから PBKDF2（SHA-256、60万回）で鍵を作り、AES-GCM（256bit）で暗号化している。
- ページを開くとパスワード入力画面だけが表示され、正しいパスワードのときだけブラウザの中で復号して表示する。
- パスワードはどこにも保存していない。ソースを見てもパスワードや中身は分からない。
- 同じタブで一度パスワードを入れれば、タブを閉じるまで入力を省略できる。
  塩がアンケートフォームと共通なので、同じパスワードならフォーム側で入れた分も引き継がれる。
- 検索エンジンに載らないよう `noindex, nofollow` を指定している。

## 入力ミスの制限

- **5回**まちがえると入力欄がロックされ、しばらく入力できなくなる。
- ロック時間はロックのたびに延びる：**5分 → 30分 → 2時間 → 24時間**（以降24時間）。
- 正しいパスワードを入れると回数はリセットされる。
- 1回の確認に最低1.5秒かかるようにして、連打できないようにしている。
- 記録はブラウザ（localStorage）に残るので、ページを開き直してもリセットされない。
- 回数や時間は `tools/encrypt.mjs` の `MAX_TRIES` と `LOCK_MINUTES` で変えられる。

## 集計を更新するとき

1. 新しい回答のtxtを `raw/` に置く
2. 自由記述・「その他」・実際の言い方は、要点を言い換えて `plain/comments.json` に追記する
   （ページ内のまとめの一文も `takeaways` にあるので、数字と合っているか確認する）
3. 集計して平文のページを作る

   ```sh
   python3 tools/build.py
   ```

4. Node.js 18 以上で暗号化して、`index.html` を上書きする

   ```sh
   PAGE_PASSWORD='パスワード' node tools/encrypt.mjs plain/summary.html index.html
   ```

5. `index.html` だけをコミットする

## 注意

- 入力ミスの制限はブラウザの中で数えているため、ブラウザのデータを消したり、別のブラウザを使ったりすると数え直しになる。
  ページを丸ごと保存して手元で総当たりする方法も防げない。中身を守っているのは暗号化なので、**推測されにくい長めのパスワード**を使うこと。
- パスワードを知っている人は、ページを開いて中身を見ることができる。
- 暗号化前の集計ページを含む過去の履歴を残さないよう、新しいリポジトリに最新版だけを移した（2026年11月）。
